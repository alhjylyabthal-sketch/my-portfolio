تطبيق «إنجاز | ملفي المهني» — حزمة جاهزة للنشر

مهم: هذا إصدار تجريبي. يحفظ النصوص والصور محليًا على جهازك، أما السحابة فترفع شاهدًا نصيًا واحدًا تختارينه، دون صور.

النشر على GitHub Pages:
1. افتحي مستودع GitHub الخاص بالتطبيق.
2. ارفعي ملفات هذه الحزمة إلى جذر المستودع (الملفات منفصلة، لا ترفعي ملف ZIP كملف واحد).
3. من Settings > Pages اختاري Deploy from a branch ثم main و / (root) واضغطي Save.
4. افتحي عنوان Pages الذي يظهر؛ يجب أن يكون الموقع عبر HTTPS. ومن الجوال اختاري إضافة إلى الشاشة الرئيسية.

تفعيل السحابة:
1. افتحي Supabase > مشروعك > SQL Editor، وانسخي محتوى setup.sql ثم اضغطي Run مرة واحدة.
2. من Supabase > Project Settings > API Keys انسخي المفتاح العام Publishable أو anon فقط.
3. افتحي موقع إنجاز، ورابط المشروع مُعبأ مسبقًا: https://udgzmrooidxsopvgqinx.supabase.co
4. الصقي المفتاح العام واضغطي «ربط المشروع» ثم «دخول» أو «إنشاء حساب».
5. إذا طُلب تأكيد البريد فافتحي رسالة التأكيد في بريدك.
6. اختاري شاهدًا نصيًا بلا مرفقات ثم اضغطي «رفع الشاهد المختار فقط».

لا تضعي Service Role Key ولا Secret Key داخل الملفات أو GitHub.
لا ترفعي بيانات الطالبات أو صورهن إلى السحابة في هذه النسخة.
إذا لم يظهر التحديث على الجوال، افتحي الصفحة مرة أخرى وأعيدي تحميلها.
