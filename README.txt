إنجاز — نسخة جاهزة للربط السحابي
1) احتفظي بنسخة احتياطية JSON من النسخة القديمة قبل أي تحديث.
2) في Supabase افتحي SQL Editor وشغلي محتوى setup.sql مرة واحدة.
3) انشري ملفات المجلد على استضافة HTTPS مثل GitHub Pages.
4) افتحي الموقع، وأدخلي رابط مشروع Supabase والمفتاح العام publishable أو anon فقط. لا تدخلي service_role أو secret.
5) سجلي حسابك بالبريد، أكدي البريد، ثم سجلي الدخول.
6) ارفعي الشواهد المحلية للسحابة أو استرجعيها. المزامنة يدوية وليست تلقائية بعد.
7) ثبتي الموقع من قائمة Chrome بعد نشره.
تنبيه: لا ترفعي صور طالبات أو بيانات حساسة قبل اختبار الصلاحيات والتحقق من سياسات الخصوصية المدرسية.
