# أكاديمية الرياضيات الصغيرة
تطبيق تعليمي مستقل للرياضيات - الصف الأول الابتدائي.
المعلمة: ابتهال الحجيلي

## الاستضافة
بعد إنشاء مستودع GitHub مستقل باسم little-math-academy، تنقل إليه ملفات هذا الفرع **إلى الجذر**.
تُفعّل GitHub Pages من الفرع main والمسار / (root).
الرابط المتوقع بعد النشر: https://alhjylyabthal-sketch.github.io/little-math-academy/

ملف الإنجاز المهني موجود في مشروع آخر، ولا تُرفع بيانات الطالب أو ملف الإنجاز إلى المستودع العام.
تخزين تقدم الطالب محلي على الجهاز؛ لا توجد مزامنة سحابية تلقائية لنتائج الطلاب في هذا الإصدار.
لأمان نشر «مغامرة اليوم»، يجب السماح بإجراءات GitHub Actions من إعدادات المستودع.
